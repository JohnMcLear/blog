# Workspace Description
This folder contains the source code and content for John McLear's personal blog, hosted at https://mclear.co.uk. 

The site is structured with:
- Root directories: `contact-me`, `more`, `privacy`, `sites`, `thanks`.
- `posts/`: Individual blog post directories, each containing content and assets.
- `index.html`: The main entry point for the site.
- `CNAME`: Configuration for the custom domain.
- `index.gmi`: Main entry point for the Gemini protocol.
- `markdown-viewer.html`: Tool for viewing .md files in a web browser.
